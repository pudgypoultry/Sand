This browser cannot run Sand

Sand simulates every voxel on the GPU with a compute shader, and compute shaders in a browser need WebGPU. This browser does not have it.

Chrome or Edge 113 and later, or Safari 26 and later, will work. Firefox is still rolling WebGPU out and may need dom.webgpu.enabled set in about:config.

On Linux, Chrome may additionally need --enable-features=Vulkan.
