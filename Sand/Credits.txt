Sand -- third-party notices
===========================

Sand is built on the libraries below. Both licences require their copyright and permission notices
to travel with any distribution of the software, INCLUDING a binary-only one -- so this file is
copied into the release package rather than only living in the repository. Handing someone a zip
with the executable and not this file is the one way to actually be in breach of either licence.

Neither library is modified. GLFW is linked as a static library; Dear ImGui's source files are
compiled directly into the executable.

  VERIFY THE COPYRIGHT LINES AGAINST YOUR VENDORED COPIES. The licence bodies below are the standard
  zlib and MIT texts and do not change, but the copyright YEAR RANGES advance with each release of
  each library, and vendor/ is not in this repository so they could not be read directly. Open
  vendor/glfw/LICENSE.md and vendor/imgui/LICENSE.txt and make the two "Copyright (c)" lines here
  match what is actually in them.

Not distributed, and so not listed above
-------------------------------------------------------------------------------

Vulkan. The build links vulkan-1.lib, which is an import stub rather than the loader itself --
vulkan-1.dll arrives with the graphics driver and is never copied into a release package. Nothing
of Vulkan's is redistributed here, so nothing of Vulkan's needs a notice. The Vulkan SDK is a build
dependency only; a tester needs a driver, not the SDK.

GLM was on the compiler's include path but was never used: no source file in this project includes a
GLM header or names anything in the glm namespace. It is therefore not part of the executable and is
deliberately not credited here -- a notice for code that is not actually present is its own small
inaccuracy. It has since been removed from AdditionalIncludeDirectories in Sand.vcxproj and from the
vendor list in BUILDING.md, so the include path and this file now agree.
